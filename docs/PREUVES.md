# Journal de preuves

Ce fichier sert de modèle. Il évite de présenter comme exécutée une étape qui n'a été que préparée.

Pour chaque TP, conserver au minimum :

- la date et la VM utilisée ;
- la commande exacte ;
- un extrait court de la sortie ;
- le résultat attendu et le résultat observé ;
- une capture seulement lorsqu'elle apporte une information absente de la sortie texte.

## Modèle

```text
TP :
Date :
VM / distribution :
Objectif :
Commande :
Résultat attendu :
Résultat observé :
Conclusion / correction éventuelle :
```

## Commandes d'identification utiles

```bash
date --iso-8601=seconds
hostnamectl
cat /etc/os-release
uname -a
ip -br address
```
